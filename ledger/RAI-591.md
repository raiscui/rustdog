# RAI-591 账本

`--put` 被打断之后, 重跑一律 `iroh_path_unknown`, 只有重启 daemon 才恢复。根因不在会话表,
在 **lane 级**: daemon 留着那条已准入的连接, 同一身份的第二条连接在 iroh 里选不到路。

## 2026-11-27 中止的 `--put` 之后第一次重跑就能续上: 重拨修路径, 不按沉默判死活

- 提交: 4831ade

### 复现 (修复前, 三真进程)

rendezvous (内嵌 relay) + daemon + 客户端, 40 MB 上传在 ~1 s 时 SIGKILL 客户端, 再按同一参数重跑:

```
retry#1 wait=0s  exit=1  error: iroh_path_unknown (transfer_id=cli-put-1795722654102697892)
retry#2 wait=2s  exit=1  error: iroh_path_unknown (transfer_id=cli-put-1795722654102697892)
retry#3 wait=5s  exit=1  error: iroh_path_unknown (transfer_id=cli-put-1795722654102697892)
retry#4 wait=15s exit=1  error: iroh_path_unknown (transfer_id=cli-put-1795722654102697892)
retry#5 wait=40s exit=0  put ok bytes=40000000 resume=honored
```

daemon 同轮 `iroh bulk refused code=iroh_path_unknown` ×4。**不是**会话表残留: 客户端被杀之后同一
transfer_id 的 open 能正常续上 —— 单进程用例 `a_lane_aborted_mid_upload_still_resumes_on_the_next_attempt`
(真 `serve_admitted` + 真会话表) 修复前就是绿的。

### 机制

准入之后 `serve_lane` 的读无超时, 对端消失 daemon 不知道; iroh 按 endpoint id 管路径状态, 同一身份
的第二条连接只有一条 `selected=false` 的直连 path (实测探针 `["selected=false relay=false
addr=ip:127.0.0.1:52458"]`, 5 s 后仍然如此), 门禁读不出就 fail-closed 成 `iroh_path_unknown`。

### 修 (最终形态)

**daemon 侧不保留任何按身份的状态, 也没有顶替逻辑。** 中间试过两版"顶替旧 lane" (无条件 / 按静默时长), 都被复核否掉并各自留下负对照:

| 版本 | 负对照读数 |
| --- | --- |
| 无条件顶替 | 传输中打一条只读 `@ping` ⇒ `upload exit=Some(1), ping exit=Some(0)`; 同身份并发 `--put` 先来的被打断 |
| 静默 6 s 顶替 | 客户端 SIGSTOP 8 s (活着但停) 期间来一条新连接 ⇒ `upload exit=1`, `发送失败: connection lost (对端已关: Reset)`, daemon `iroh lane superseded` ×1 |

"静默"这个判据本身是错的: 复核给的换算是按真实线上帧 349,606 B (base64 1.33 倍) 计的, 6 s 只相当于 58 kB/s; 比这更慢的链路会把活着但慢的传输判成死的。所以最终形态把判据整个拿掉, 只留**事件**:

- `log_lane_closed`: 连接真关时记 `iroh_lane_closed session=… reason=…` (排障要的是对端给的关闭原因, 不是我们猜的死活)。
- 客户端 `--put` / `--get` 撞 `iroh_path_unknown` (可重试码) 按 2 s 间隔重拨, 预算 18 s; 重拨不碰任何活着的 lane —— 没有顶替逻辑可碰。**重拨本身是修路径的手段**: 实测重拨在 8.16 s 拿到可用路径, 不重试时那条死连接要 30.0 s 才被传输层放掉 (复核实测; 整条命令 52 s / 36 s)。所以这里不写"熬到过期"。
- lane 写失败的错误文本带对端连接状态 (`对端已关: …` / `对端连接仍开着`)。

### 未验 / 边界

- 跨网/真实 relay 拓扑下的同一读数 (本轮 e2e 是回环 + 内嵌 relay, 直连路径)。
- Windows 侧执行 (`scripts/ci/run-integration-targets.py` 登记为 `unix`: 用例用 `HOME`/`TMPDIR` 隔离); 各平台执行 target 数: ubuntu 13 / macos 13 / windows 2。
- daemon 那条死连接在被传输层关掉之前仍占着这条身份的选路; 重拨能把路径修好 (实测 8.16 s), 但"哪一次重拨正好赶上"没有模型 —— 跨网慢链路上预算 18 s 可能不够, 届时表现为 `iroh_path_unknown` 后 exit 1, 再跑一次即续传。
