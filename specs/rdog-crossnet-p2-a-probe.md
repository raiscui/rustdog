# P2-A 目录、目标授权与有界租约的隔离实验

状态：临时实验，面向 [#128](https://github.com/raiscui/rustdog/issues/128) 已冻结的行为。不是生产协议、授权决议或配置，现有正式端面不变。

## 目录与目标授权

实验把注册者、查询者和目标准入分开。目录通过 iroh 握手认证身份，使用一个明确配置的目标名/注册者/查询者组合。注册宣告的 endpoint ID 必须和握手身份相同。有效条目保存单一实例；同名竞争只允许一个实例生效。续租与注销须命中当前实例，旧 fence 不能操作替换项。到期条目不能被解析。没有该目标查询许可的主体得不到 endpoint 地址。

数据连接通过 iroh 认证通信双方。实验以预置的内存许可表给出可独立变化的测试输入，比较认证主体、认证 endpoint、请求目标名和未过期租约。错目标、错身份、错 endpoint、逾期或未签发的测试句柄都在 handler 之前被拒绝。句柄、合成 JSON 和短时限仅是实验夹具，不是对准入格式、生产签发方式或凭证期限的选择。

## 有界租约和回收

确定性单元测试把时间显式传给状态机，不改系统时钟。回环进程使用单调时钟走真实短租约，以 [iroh_p2_probe.rs](../tests/manual/iroh_p2_probe.rs) 的 `TTL` 为准。只有有效期内且云探针经过认证 round trip 的续租才延长原会话；续租失败不改原截止时间。停止独立的云 endpoint 后，新会话和续租均明确拒绝；已经获准的同一连接可在原期限内探活，到期即关闭，不能进入新操作。运行器逐例隔离进程和网络，并观察连接、内存状态和临时 HOME 的回收。

## HOLD

保持 [#113](https://github.com/raiscui/rustdog/issues/113)、[#114](https://github.com/raiscui/rustdog/issues/114) 的未决点：准入凭证的最终格式与期限、权威策略来源、撤销传播的先后顺序。本实验没有选定任何一个，没有测试主动撤销协议或生产租约一致性，也没有引入其他命令能力、bulk 或公网配置。
