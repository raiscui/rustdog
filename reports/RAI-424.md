# RAI-424 可续传半成品的持久化索引

> 结论: 已落地并推 draft PR (**已推待合**). 未合并, 合并由 Captain 决定.

## 1. 结论

RAI-417 让半成品在**进程存活期间**可取消、可过期回收, 但会话表 `TRANSFERS` 只在内存里. daemon 一重启,
盘上留着的半成品就没有任何东西知道它属于哪个目标, 于是三件事同时失效:

- **续传从 0 重来**: 客户端 `resume:true` 拿到 `offset = 0`, 把已收字节覆盖掉 —— 这是静默重传,
  正是本 lane 反复要防的那类失败.
- **TTL 回收扫不到它**: sweep 只看内存表, 重启后的半成品既不会被回收也不会被报告, 变成永久残留.
- **同目标再传一次会另起一个暂存名**, 两份半成品同时存在, 谁都不是"真相".

修法是给半成品加一份**持久化索引**: 会话一落盘就写, 重启时重建, 之后续传与 sweep 都按索引工作.

| 测试 | 4 条验收用例 + `forget_sessions_for_tests(&[ids])` (模拟重启) 与线程级索引路径 override |

### 2.1 索引只回答"去哪里找", 不回答"进度是多少"

`written` 一律取暂存文件长度, `last_activity_ms` 一律取文件 mtime. 规格 §2.5 已经把这两件事定为
续传 offset 与活性判定的真相源; 索引里再存一份进度, 就是给同一件事两个答案 —— 重启后二者不一致时
没有任何依据判断谁对. 索引里只存 `transfer_id` / `target_path` / `temp_path` / `size` / `sha256`.

### 2.2 三条 fail-closed 纪律

1. **账本读不懂就不认账**: 索引缺失、不可读、不是合法 JSON、缺 `transfers` 数组 → 本次不恢复任何条目,
   只 warn, **不动盘上任何文件**. 宁可让半成品暂时无人认领 (人工可清), 也不能在一知半解上删文件或
   把它当成新传输从 0 覆盖.
2. **索引项指向的文件不存在 → 丢掉该条**: 不假装传输还在, 否则 `@file-end` 会去 rename 一个不存在的路径.
3. **进度只从文件本身取** (见 2.1).

落盘失败 (目录建不了、磁盘满) 只 warn, 不让正在进行的传输失败 —— 索引是恢复用的元数据, 不是传输的
前置条件. 反过来, 会话结束时必须能从索引里消失, 否则重启后会把已提交的传输当成还在.

### 2.3 一个测试隔离的坑 (值得记)

索引路径 override 最初是**进程全局**的 `OnceLock<Mutex<Option<PathBuf>>>`, 结果是"单跑绿、全量红":
并行用例的正常落盘会盖掉另一个用例刚写的损坏索引. 改成 **thread-local** (`cargo test` 每个用例一个线程),
且未设置的测试线程返回 `None` 让落盘/恢复一律 no-op —— 既不写进真实用户目录, 也不互相覆盖.
同类纪律见 `docs/solutions/best-practices/parallel-test-global-state-single-lock.md`.

## 3. 验收 (按 RAI-424 口径逐条)

| 验收项 | 用例 | 结果 |
| --- | --- | --- |
| ① 中断 → 重启 → TTL 后回收无残留 | `restored_index_lets_the_sweep_reclaim_after_restart` | 重启后 `restore_index() == 1`, sweep 回收 1 条, 暂存文件`!exists()` |
| ② 重启后 `resume:true` 的 offset 非 0 且字节连续 | `restored_index_resumes_from_the_partial_length` | `resume_honored == true`, `written == 5` (盘上长度), 不是 0 |
| ③ 索引损坏或路径不存在时 fail-closed | `corrupt_index_is_ignored_and_leaves_files_untouched` / `missing_index_restores_nothing_and_creates_nothing` | 损坏 → 恢复 0 条、暂存文件保留、不出现在 `@file-list`; 缺失 → 恢复 0 条且不凭空创建文件 |

  无限增长"的现场, 那是另一个缺陷, 不在本票范围.
